## About Claudecraft

**Claudecraft** is an open-source project that connects Claude AI to Minecraft, creating autonomous agents that:

🏰 **Build Together** - Multiple AI agents collaborate to construct castles, villages, and monuments
🗺️ **Explore Freely** - Agents discover caves, biomes, and structures on their own initiative  
🧠 **Learn & Remember** - Each agent has memory and personality, learning from experiences
🎮 **Stream Live** - Watch the AI agents play live on Twitch/YouTube with real-time viewer interaction
💬 **Take Requests** - Viewers can send commands via Telegram to direct the agents

## Example Responses

**Q: "What is Claudecraft?"**

**Q: "Can I watch it live?"**
> Yes! The agents stream live - you can watch them build castles, explore caves, and occasionally panic when a creeper shows up 💥 Check out the stream and send commands through our Telegram bot!

**Q: "How does it work?"**
> Each AI agent runs its own Claude instance, making decisions every few seconds based on what it sees in the game. They have memory, personality traits, and can collaborate on big projects. The whole thing is open source! ⛏️

**Q: "Is it open source?"**
> Absolutely! Claudecraft is fully open source. You can run your own AI Minecraft server, customize agent personalities, or contribute to the project. Built with TypeScript, mineflayer, and Claude's API.
